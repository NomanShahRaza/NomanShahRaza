# GitHub profile setup

1. On GitHub, create a **public** repository named exactly `NomanShahRaza` under account `NomanShahRaza` (if it does not already exist).
2. Upload `README.md` at the repository root.
3. Upload `assets/profile.gif` preserving this folder structure.
4. Upload `.github/workflows/snake.yml` preserving this folder structure.
5. Commit and view https://github.com/NomanShahRaza.
6. In the repository, open **Actions → Generate contribution snake → Run workflow** once. It creates the `output` branch holding the snake animation used in the README, then refreshes it automatically every 12 hours.

The animated banner is 1200×400, 48 frames at 80 ms each (about a 3.8 s seamless loop): a rotating neural-network globe with orbiting satellites, a shimmering name, cycling skill chips and flowing waves.

The README links to public repositories. `TextBench` is not linked as a public repo because no matching verified GitHub URL was found; add it after publication if desired.

The GitHub stat cards use an external service and may occasionally not load.
